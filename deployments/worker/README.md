# Worker deployment

Run a persistent Bun process with workspace dependencies installed: `bun run --cwd apps/worker start`. It shares the API service code, but runs separately from HTTP request handling. Supply `CONVEX_URL`, a deployment-specific `CONVEX_DEPLOY_KEY`, private R2 S3 credentials, and `SUME_BASE_URL`/`SUME_API_KEY` as hosting secrets. Pricing settings must match the API. No credentials belong in a client bundle or Convex environment.

Use the same Convex deployment and R2 bucket as the corresponding API. Start the API and worker only after deploying the matching Convex schema/functions. Allow graceful shutdown for active tasks; leases recover abrupt exits. The current worker has three concurrent lanes per process. Scale instance count deliberately to control total provider concurrency.

Manual timeline exports run in the same leased worker, independently of the AI provider. Install FFmpeg and FFprobe with H.264/AAC encoding, `drawtext`, `xfade`, and `acrossfade` support, plus Fontconfig and DejaVu Sans/Serif/Mono fonts. On Debian-based hosts the relevant packages are `ffmpeg`, `fontconfig`, and `fonts-dejavu-core`. Optional `FFMPEG_PATH` and `FFPROBE_PATH` select installed binaries. The worker needs a writable temporary directory with at least 1 GB free per active render and access to the private R2 bucket. Allow up to three concurrent tasks per process when sizing CPU, memory and temporary disk.

Deploy the matching timeline schema/indexes/functions, API, clients and worker together. Manual exports never submit an AI task or reserve credits. Source downloads are limited to registered immutable objects owned by the project owner. Output registration is fenced by the existing worker lease, temporary output keys remain eligible for garbage collection until registration, and storage interruptions retry the same export snapshot. Missing tools or invalid media produce a retryable user-visible export failure. No Sume credentials are required for a worker used exclusively for manual exports.
